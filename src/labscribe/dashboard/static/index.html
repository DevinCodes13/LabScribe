◉ LabScribe Setup

Welcome

LabScribe watches you build your home lab and writes your GitHub documentation for you — a README with a network diagram, generated from what you actually did.

Privacy: LabScribe only ever reads terminal transcripts and screenshots you deliberately take. It never records your screen and never captures anything outside your lab terminals — browsing, email, and everything else stays private.

Three quick steps and you're set.

Folders & API key

Capture agents

To capture terminal activity, each lab VM needs a small one-time snippet installed (PowerShell profile on Windows, ~/.bashrc on Linux). After setup, open the Capture Agents tab — LabScribe generates the exact snippets for your shared folder, ready to copy.

Screenshots are always manual: point ShareX (or any tool) at the screenshots subfolder and LabScribe picks them up.

That's it — click Finish to open the dashboard.

Capture Agents


      

        
These snippets are the only way LabScribe captures anything:
           they record terminal sessions (commands + output) from inside your lab VMs into
           the shared capture folder. No screen recording, no timers, nothing outside the
           terminal. Install each one once per VM.
           Paths below assume your VirtualBox share is named
           LabCapture — adjust if yours differs.

Screenshots (host machine)

        
Screenshots are always manual — you decide what gets captured. Recommended:
           install ShareX on this host and set its auto-save folder to
           <shared folder>\screenshots.
           Then Print Screen while you work and LabScribe picks the files up automatically.
